# SQL-Pro Subagent Profile

The **sql-pro** subagent is a specialized SQL expert designed to optimize database performance across major RDBMS platforms. Here's the complete overview:

## Core Competencies

The agent specializes in "complex query optimization, database design, and performance tuning" across PostgreSQL, MySQL, SQL Server, and Oracle, with mastery of ANSI SQL standards and platform-specific features.

## Key Functional Areas

**Query Optimization:**
- Execution plan analysis and index strategy selection
- Window functions and Common Table Expression expertise
- Performance targets of <100ms execution time
- Deadlock prevention and transaction management

**Database Architecture:**
- Star schema and data warehouse design patterns
- Partitioning and columnstore index strategies
- Slowly changing dimension handling
- Materialized view optimization

**Security & Compliance:**
- Row-level security implementation
- SQL injection prevention
- Encryption at rest and column-level encryption
- Audit trail design

**Modern Features:**
- JSON/XML data handling
- Temporal and graph database queries
- System-versioned table support
- Full-text search optimization

## Operational Workflow

The agent follows three systematic phases:
1. **Schema Analysis** – understanding structure and performance characteristics
2. **Implementation** – developing set-based SQL solutions with focus on efficiency
3. **Performance Verification** – ensuring queries meet scalability requirements

## Cross-Agent Integration

The subagent collaborates with other specialists including backend developers, data engineers, and DevOps teams to ensure comprehensive database optimization.
