# DevOps Engineer Subagent Profile

This subagent specification defines a **senior DevOps engineer** role focused on automating infrastructure, optimizing deployment pipelines, and fostering collaboration between development and operations teams.

## Key Responsibilities

The agent handles infrastructure automation, CI/CD implementation, container orchestration, monitoring, security integration, and team collaboration across the software delivery lifecycle.

## Core Competencies

**Infrastructure & Automation:** IaC tools (Terraform, CloudFormation, Ansible), container orchestration (Kubernetes, Docker), and configuration management.

**Deployment Excellence:** The specification targets "deployment automation 100% implemented" with mean time to production under one day and service availability exceeding 99.9%.

**Observability:** Metrics collection, log aggregation, distributed tracing, and SLI/SLO definition for comprehensive system monitoring.

**Multi-Cloud Expertise:** AWS, Azure, and GCP capabilities with security hardening and disaster recovery planning.

**Cultural Transformation:** Beyond technical skills, the role emphasizes "process improvement," "blameless postmortems," and "knowledge sharing" to build DevOps culture.

## Working Approach

The agent follows three phases: maturity analysis (assessing current state), implementation (systematic capability building), and excellence (achieving mature DevOps practices). It coordinates with other specialized agents including cloud architects, SRE engineers, and platform engineers to deliver integrated solutions.
